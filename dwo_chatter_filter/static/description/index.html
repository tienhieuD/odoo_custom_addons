Message Filter on Chatter for Odoo

Stop scrolling through the whole chatter.

A Filter by: row of coloured badges above the messages: click one to see only discussions, emails, notes or tracking.

A long-lived record has hundreds of messages: talks, emails, notes, changed fields and automatic notices, all mixed. The search box only finds words. Message Filter on Chatter shows one kind at a time, with the number of messages of each kind.

A count on each

You see how many messages of each kind before you click.

One click

One kind at a time: the badge fills with its colour. Click All to come back.

Done by the server

Load more works on the filtered list, not only on what is loaded.

Every message once

Always All on open

Install the module

1. Copy the dwo_chatter_filter folder into an add-ons path of your Odoo server.

2. Restart Odoo, activate developer mode and click Update Apps List in the Apps menu.

3. Search for Message Filter on Chatter and click Install.

Reload your browser page after installing so the new assets are loaded.

Filter the messages

Under Filter by:, click a badge to see that kind of message only. Click All to see everything again.

What each badge holds

Discussions: Send message. Emails: emails received and sent. Notes: Log note. Tracking: changed fields. Other: automatic messages and the rest.

A badge with no message is greyed out.

Good to know

It works in the chatter of a record, not in Discuss or the inbox.

One kind at a time. While you search messages with the magnifier, the badges are hidden.

Frequently Asked Questions

In which badge is an email sent from the Email Composer?

In Emails. It is an outgoing email, even though it has the subtype of a discussion.

Where are the changes of a field?

In Tracking, whatever their subtype.

Is my choice kept?

No. Open the record again and all the messages are shown, so nobody misses a message without knowing.

Does Load more work when a badge is chosen?

Yes. The server returns only that kind, so Load more goes on in the filtered list.

Does it work with other modules that change the chatter?

It adds one row above the messages and does not touch the messages themselves. It runs together with the Email Composer.
