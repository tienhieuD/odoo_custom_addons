Installation

Requires libwebp on your server so Pillow can encode WebP images. One-time setup — follow the steps for your environment.

Linux (Ubuntu / Debian)

sudo apt install -y libwebp-dev
sudo /opt/odoo/venv/bin/pip install --force-reinstall --no-binary Pillow Pillow
sudo systemctl restart odoo

Windows

Pillow's official Windows wheel already includes WebP — no extra install needed.

pip install --upgrade Pillow

macOS (Intel)

brew install webp
/path/to/venv/bin/pip install --force-reinstall --no-cache-dir --no-binary Pillow Pillow

macOS Apple Silicon (M1 / M2 / M3 / M4)

Homebrew on Apple Silicon uses /opt/homebrew/ instead of /usr/local/. You must set library paths explicitly — otherwise Pillow compiles without WebP support even though libwebp is installed. 

brew install webp
LDFLAGS="-L/opt/homebrew/lib" CPPFLAGS="-I/opt/homebrew/include" \
  /path/to/venv/bin/pip install --force-reinstall --no-cache-dir --no-binary Pillow Pillow

Verify it works

python -c "from PIL import Image; import io; img=Image.new('RGB',(1,1)); out=io.BytesIO(); img.save(out,format='WEBP'); print('OK, bytes:', len(out.getvalue()))"
# Expected output: OK, bytes: 44

FAQ

Does WebP look different from the original?
No. At quality 85, WebP is visually indistinguishable from JPEG at quality 95. PNG images with transparency are losslessly converted — no quality loss at all.

Will it slow down my server?
Only the very first request for each image triggers conversion (~90ms for a typical product image). Every request after that is served from cache at ~6ms — faster than a CDN, at no recurring cost.

What happens when I update a product image?
The cache is keyed by the image's last-modified timestamp. Updating an image automatically bypasses the stale cache — a fresh WebP is generated on the next request, no action needed.

What if a visitor's browser doesn't support WebP?
They receive the original image unchanged. All modern browsers support WebP. Older browsers and bots are handled gracefully — nothing breaks.

Does it work with multiple Odoo websites?
Yes. Each website has its own toggle, quality setting, and isolated cache. Changing settings on one website never affects another.

I get "KeyError: WEBP" in the Odoo log.
Pillow was installed without the WebP encoder. Install libwebp-dev (Linux) or run brew install webp (macOS), then reinstall Pillow from source using --no-binary Pillow as shown above. The module logs the exact command to run.
