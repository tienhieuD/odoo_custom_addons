Record Concurrency Control Pro

Prevent Data Conflicts and Enhance Team Collaboration in Real-Time

In multi-user environments, simultaneous editing of the same record can lead to data overwrites, lost work, and frustration. Record Concurrency Control Pro solves this by providing intelligent detection, warnings, and resolution options to ensure data integrity and smooth collaboration.

Key Features

  • Real-Time Edit Detection: Instantly notifies users when another person starts editing the same record.
  • Smart Concurrency Warnings: Displays clear dialogs with options to force save, discard changes, or cancel for review.
  • Visual Conflict Resolution: Shows a detailed table comparing your local changes with the latest server data, highlighting differences for fields like text, dates, many-to-one, many-to-many, and binary files.
  • Multi-Tab Support: Seamlessly handles edits across multiple browser tabs, preventing conflicts within the same user session.
  • Bus Integration: Leverages Odoo's real-time bus system for instant notifications without performance overhead.
  • Automatic Stale Detection: Marks records as "stale" when updated by others, prompting users to reconcile changes.
  • Flexible Save Options: Choose to overwrite server data, discard local changes, or review before proceeding.
  • Browser Unload Protection: Prevents accidental navigation away from unsaved, conflicting changes.

How It Works

  1. A user opens a record for editing.
  2. If another user edits and saves the same record, the first user receives a notification.
  3. The system marks the record as stale and shows a warning dialog with change details.
  4. The user can review differences, force save, discard, or cancel to avoid data loss.

Benefits

  • Eliminates Data Overwrites: Prevents accidental loss of important updates.

  • Enhances Collaboration: Allows teams to work simultaneously without fear of data corruption.
