The Problem

In multi-user environments, it is common for two or more users to edit the same record at the same time. Without proper control, the last save overwrites previous changes, leading to data loss, inconsistencies, and costly mistakes.

The Solution

This module introduces real-time concurrency detection, intelligent warnings, and visual comparison tools to help users resolve conflicts safely and efficiently.

Key Features

  • Real-time detection when another user edits the same record
  • Clear warning dialogs with flexible resolution options
  • Visual comparison between your changes and server data
  • Supports text, dates, relational fields, and binary data
  • Multi-tab awareness to prevent self-conflicts
  • Automatic stale record detection
  • Options to overwrite, discard, or review changes before saving
  • Protection against accidental navigation with unsaved changes

How It Works

  1. User A opens a record and starts editing
  2. User B updates and saves the same record
  3. User A is notified immediately about the change
  4. The system highlights differences and offers resolution options
  5. User A decides to overwrite, discard, or review changes
