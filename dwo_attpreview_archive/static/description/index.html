Secure Archive Preview: ZIP, RAR, 7Z, TAR

Browse archives in Odoo without extracting them.

See what is inside a zip, rar, 7z or tar file as a folder tree, then open any file inside in place.

Click an archive in the chatter or in a file field: its folders and files appear as a tree, with sizes and dates. Click a file and it opens on top with the preview engines you have, or download just that file. A zip inside the archive opens the same way, level after level. The archive is read on your Odoo server and never extracted to disk. Works with the free Secure Attachment Preview module, installed automatically.

Key Features

Folder tree

Folders first, natural order (file2 before file10), sizes, dates and a file count per folder. Expand, collapse and move with the keyboard.

Fast with huge archives

Only the visible rows are drawn, so an archive of tens of thousands of files scrolls smoothly. Filter by name to find a file deep in a folder.

Open files inside

PDF and pictures open with the free core; Word, Excel and PowerPoint with Secure Office Preview; emails with Secure Email Preview. Any file can be downloaded alone.

Safe by design

Nothing is written to disk. Zip bombs and files over the size limit (default 500 MB, set in Settings) are refused, password protected files are marked, and Odoo access rights apply at every level.

Formats

zip, tar, tar.gz, tar.bz2, tar.xz, gz with no extra installation; rar (files inside open when unrar is on the server); 7z when the py7zr Python package is installed.

No extra dependency required

The module installs on any Odoo server. Optional tools add rar extraction and 7z; without them a clear message says what to install.

Frequently Asked Questions

Is the archive extracted on the server?

No. Only the list of files is read; a file is decompressed in memory when you open or download it, and nothing is written to disk.

Can it open very large archives?

Yes. The tree draws only the visible rows, so tens of thousands of files scroll smoothly. Up to 100 000 entries are listed.

Do I need to install anything for rar and 7z?

Not to install the module. RAR archives are always listed; opening a compressed file inside needs unrar on the server. 7z archives need the py7zr Python package. Without them, a message says what to install.
