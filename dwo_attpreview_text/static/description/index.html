Secure Text & Code Preview: MD, HTML, XML, JSON, YAML, LOG

Raw text, rendered preview and tree view for text files in Odoo.

Open Markdown, HTML, XML, JSON, YAML, logs, code and more in the preview window, with the view that fits each file.

Click a text or code file in the chatter or in a file field. A bar at the top switches between Raw (line numbers and syntax colours), Preview (rendered Markdown, HTML and notebooks, logs coloured by level, diffs side by side) and Structure (a tree of JSON, XML, YAML, TOML and INI files, the outline of a Markdown file). Only the views that make sense for the file are shown. Works with the free Secure Attachment Preview module, installed automatically.

Key Features

Raw text, made readable

Line numbers, syntax colours for about 40 languages, wrap long lines, find with Ctrl+F, go to a line with Ctrl+G, copy the whole text.

Preview

Markdown with a table of contents, HTML pages, Jupyter notebooks with their outputs, logs coloured and filtered by level, diffs side by side, subtitles and PO translations as tables.

Structure

JSON, XML, YAML, TOML and INI as a tree you can fold, filter and search, with the path of each value. Markdown headings as an outline that jumps to the line.

Fast with big files

Only the visible lines and tree rows are drawn: a log of 200 000 lines or a JSON file of 100 000 values scrolls smoothly. Up to 10 MB of text is shown.

Safe by design

HTML and Markdown are shown in a sandboxed frame: no script runs and nothing is loaded from the internet. HTML is sanitized on your server, XML is read with entities turned off.

Any encoding

UTF-8, UTF-16 and UTF-32 with or without BOM, and older encodings such as Windows-1252, are detected. A binary file with a text name is refused with a short message.

Frequently Asked Questions

Which files does it open?

Markdown (md, mdx), HTML, XML (xml, xsd, xsl, rss, plist...), JSON (json, jsonc, geojson, jsonl, ipynb), YAML, TOML, INI, cfg, conf, env, properties, code (py, js, ts, css, scss, sql, sh, java, c, cpp, cs, go, rs, php, rb and more), log, diff, patch, srt, vtt, po, pot, txt and rst. Text files that Odoo shows as plain text open in this viewer too.

Can an HTML or Markdown file run a script?

No. HTML is cleaned on your server first, then both are shown in a sandboxed frame that allows no script and loads nothing from the internet. Pictures from the internet are replaced by a small placeholder, and a note says how many were not loaded.

What about very large files?

Only the lines on screen are drawn, so hundreds of thousands of lines stay smooth. Up to 10 MB of text is shown; a larger file shows its first 10 MB with a note. Syntax colours are used up to 1.5 MB.

Can I edit the file?

No, the viewer is read-only. You can copy the text, or download the file.
