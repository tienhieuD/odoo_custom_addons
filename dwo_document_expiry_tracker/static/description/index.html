Universal Expiry Automation for Odoo

Track, alert, and govern expiry for any Odoo model with flexible rules, custom domains, and real-time form alerts.

Contracts, certificates, permits, supplier docs, quality records, and custom objects all expire differently. This module lets you define rule-based expiry logic per model, manage custom expiry dates when no native date field exists, and notify exactly the right people through bus and email before risk turns into incidents.

⚠️ Why Teams Need This

  • Manual spreadsheet tracking misses critical deadlines.
  • Different models require different expiry logic and recipients.
  • Users need clear warnings directly while opening records.
  • Audit and compliance teams need logs and dashboards, not guesswork.

✨ Key Features

🧠 Rule Engine by Model

Configure expiry rules for any model with base, before, and after domains.

📅 Flexible Date Logic

Use model date fields, custom per-record expiry dates, or field + override mode.

📣 Smart Recipient Targeting

Notify responsible user, followers, selected users, selected groups, dynamic user domain, or all internal users.

🖥️ Real-Time Form Alerts

JS checks matching rules when form view opens and shows OR-rule alert messages with user limit and summary mode.

📊 Dedicated Dashboard Data

Separate tracking, queue, and log tables for list/pivot/graph reporting and audit history.

♻️ Auto Housekeeping

Rule-level cleanup policy powered by @api.autovacuum for old queue/log data.

🎯 Designed For

  • Compliance Teams: ISO, SOC2, GMP, HSE, legal document governance.
  • Operations: supplier certifications, maintenance contracts, quality files.
  • IT/Admin: central rule management with low-noise notifications.
  • Custom Odoo Projects: any model can become expiry-aware immediately.

🚀 What Users Get

  1. Admin configures rules and recipient strategy once.
  2. Cron scans and classifies upcoming/expired records automatically.
  3. Notifications are dispatched via bus/email with dedupe protection.
  4. When users open records, access alerts are shown if rules match.
  5. Each user can mute alerts, limit popup count, or ignore selected alerts.
