List Header Filter: Quick Column Filter

Filter a list from the column you are looking at.

A small funnel in every column header. Click it, pick the values or dates you want, and the list is filtered: no need to open the search bar, add a custom filter and build the condition.

Live demo: demo-headerfilter.duotek.io.vn (sign in as demo_alice, password demo)

To filter a list in Odoo you normally open the search bar menu, add a custom filter, choose the field, the operator and the value, then apply. This module puts that work where you are already looking: a filter icon in each column header. The filter you make is a normal facet of the search bar, so you can still see it, edit it, save it as a favourite or remove it from there.

What you get

Checkboxes with search

Selection, many2one and many2many columns list their values with checkboxes and a search box. Ticked values move into an area on top; untick one to drop it. A "Not set" choice is there for fields that can be empty.

Quick dates and fiscal year

Date and datetime columns offer Today, Yesterday, Tomorrow, this and last week, month, quarter and year, the last or next 7 and 30 days, and the fiscal year (1 April to 31 March). Or pick one day, or a range of days.

Odoo's own operators

Text columns: contains, does not contain, equals, does not equal, is set, is not set. Numbers: equals, not equal, greater, lower, between. Yes or No for checkboxes.

One search bar

Each filtered column becomes a facet of the search bar and is combined with the other facets. Remove the facet there, or click Reset in the popover, and the other side follows. The icon of a filtered column stays lit; the others show it only when the pointer is on the header, so the lists stay clean.

Right time zone

Days start and end in your browser's time zone, the one Odoo uses to show dates and times, and are sent to the server in UTC. A filter on Today at the end of the evening still means your today.

Plays well with others

Installed with the DuoTEK list sticky header and column freeze module, the two small boxes sit side by side on the header, both work and a frozen column stays frozen when you filter.

Filters on the column headers

The funnel shows when the pointer is on a column header, in a small framed box like the pin button. A filtered column keeps its icon lit in the colour of your theme, and its condition is a facet in the search bar, next to the ones you typed or chose there.

Checkboxes, chosen values on top

Many2one, many2many and selection columns. The values you tick go to the area on top, so you always see what the filter contains; untick a value there to remove it.

Limitations

What to expect, so there are no surprises.

Lists with a search bar

The icons are on the lists that have a search bar: an action's list, or a list in a selection dialog. A list embedded in a form (order lines and other x2many fields) has no search bar to join, so it gets no icons.

Fields that can be searched

Text, number, checkbox, date, selection, many2one, many2many and one2many fields that Odoo can search. A computed field that is not searchable has no icon.

Fixed fiscal year

The fiscal year is 1 April to 31 March, it is not read from the company settings. Weeks start on Monday.

Ranges are fixed when applied

Today, This week and the other quick ranges are turned into dates when you click them, like a filter built by hand. A list left open overnight keeps the day it was filtered on.

Editing the facet

If you change the facet with Odoo's own domain editor, it keeps filtering but is no longer tied to the header icon; use the icon's Reset or remove the facet.

Related values

Many2one and many2many values come from the related model with Odoo's name search, so they follow your access rights; long lists are loaded 30 at a time with a Show more button.

Shown on hover

The funnel of a column that is not filtered shows only while the pointer is on its header; on a touch screen tap the header first. Columns whose value is not a plain field (activity icons, drag handles) have none.

Requirements & Installation

The module depends only on the standard web module and needs no external Python library.

  • Install

Install the module

1. Copy the dwo_listview_header_filter folder into an add-ons path of your Odoo server.

2. Restart Odoo, activate the developer mode, update the apps list, and install List Header Filter: Quick Column Filter.

3. Open any list view: the funnel is in each column header. No settings, menus or data are added.

Frequently Asked Questions

Does it change my data or add fields?

No. It only adds filters to the list views you already use, the same domains you could build by hand in the search bar. It adds no models, fields, menus or settings.

Can I save a header filter as a favourite?

Yes. It is a normal facet of the search bar, so Save current search keeps it, together with the other facets.

Several values in one column?

Tick as many as you like: the column shows the records that have any of them. Filters on different columns are combined with AND.

Does it work with the sticky header and column freeze module?

Yes, it is made to be installed next to it: the pin button and the filter icon do not overlap and a frozen column stays frozen when you filter.

Which Odoo versions?

The same module is published for the recent Odoo releases, Community and Enterprise: pick your version in the version selector of this page.
