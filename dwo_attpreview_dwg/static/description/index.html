Secure DWG Preview: AutoCAD drawings

Open AutoCAD DWG drawings right inside Odoo, free.

Pan, zoom and switch layers of a DWG drawing from the chatter or a file field, with nothing to install on the server.

Click a DWG file in the chatter or in a file field. The drawing is converted to DXF in your browser by LibreDWG (WebAssembly) and drawn like the DXF files of the Secure CAD Preview module. Drag to pan, scroll to zoom, use the Layers list. Works with the free Secure Attachment Preview module, installed automatically. This module is free and open source (GPL-3).

Key Features

No converter on the server

Nothing to install and no external tool to call: the conversion runs in the browser of the person who opens the file.

Layers

A list with the colour of each layer and a switch to show or hide it, plus a fit-to-view button and a dark background.

Free and open source

Licensed GPL-3, because it bundles LibreDWG. The source of the bundled libraries is named in the module.

Files never leave your server

The viewer is bundled in the module and runs in a sandboxed frame with no network access. Nothing is uploaded to a conversion service, a CDN or any other site.

Same rights as Odoo

A user can preview a file only if Odoo lets them read that attachment or record. The check is made again when the file is handed to the viewer.

Size limits you control

Each group of file types has its own limit in Settings, so a large model does not slow the server.

Frequently Asked Questions

Which DWG versions does it open?

The versions that LibreDWG reads, from AutoCAD R13 up to recent releases. A file that cannot be read gets a clear message and a Download button.

Is everything in the drawing shown?

The common 2D entities are. Complex drawings may show with missing details, and 3D content is not drawn. Treat the preview as a quick look, not as the exact drawing.

Is anything sent to another server?

No. The drawing is converted and drawn in your browser, in a sandboxed frame with no network access.

How large can a file be?

30 MB by default; change it in Settings.
