# 20.0.0.3

Port of `19.0.0.3` (see `19.0.0.2.md` / `19.0.0.3.md`) to Odoo 20.0. Differences:

- `ListRenderer.rootRef` is a signal ref in Owl 3: the root element is `this.rootRef()` (not `rootRef.el`).
- Header `<th>` no longer has `data-tooltip-delay="1000"`: pin buttons are added to `th[data-name]`.
- `static/src/xml/style.xml` removed: its xpath on `th[@data-tooltip-delay='1000']` no longer matches in 20
  (it would break the web client). The pin button is added by `main.js` only.
- `--ListRenderer-thead-bg-color` is a translucent gradient in 20: the sticky header uses
  `background: var(--ListRenderer-thead-bg-color), var(--body-bg, #fff)` so scrolled rows do not show through.
- Not browser-tested yet.
