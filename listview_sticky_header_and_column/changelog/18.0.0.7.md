# 18.0.0.7

Module `listview_sticky_header_and_column` (Odoo 18.0). Previous version: `18.0.0.6`.

- Fixed: the handle (drag to reorder) column no longer gets a pin button. Every other data column still has exactly one (Odoo 18 has no `<column>` groups, so no column was missing a button).
- The pin button is now attached by `thead tr th[data-name], thead tr th[tabindex]` minus the checkbox, handle, button, open-form and optional-columns headers, as in 19 and 20.
- Tests: one new tour on the Order Lines of a sales order (button once per data column, none on the handle, pin keeps that column and all on its left while scrolling, unpin).
