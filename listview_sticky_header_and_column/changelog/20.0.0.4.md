# 20.0.0.4

Module `listview_sticky_header_and_column` (Odoo 20.0). Previous version: `20.0.0.3`.

- Pin icon uses the Material Symbols `push_pin` glyph (FontAwesome is gone in 20). Sticky header `background` is split into `background` + `background-color` (the layered shorthand was invalid when the variable is a plain colour, so embedded headers were transparent). The pin button shows on lists embedded in a form (`.o_list_renderer` hover rule).
- Found with the `lab/listview_sticky_test_lab` test bed (pin + scroll checks on wide fake lists).
