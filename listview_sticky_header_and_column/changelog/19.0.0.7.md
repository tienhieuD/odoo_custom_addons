# 19.0.0.7

Module `listview_sticky_header_and_column` (Odoo 19.0). Previous version: `19.0.0.6`.

- Pin buttons are now added to every data header (`thead tr th[data-name]` or labelled `th`), and no longer to the handle, checkbox, button, open-form and optional-columns headers. In Odoo 19 all Order Lines data columns already had a button (they are plain fields); the old selector (`data-tooltip-delay`) also gave the handle column a useless one.
- Saved pins keep working (the stored value was already the column position).
- Tests: one new tour on the sales order lines (one button per column, pin keeps that column and all on its left while scrolling, unpin, none on the handle).
