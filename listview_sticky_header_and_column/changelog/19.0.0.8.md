# 19.0.0.8

Module `listview_sticky_header_and_column` (Odoo 19.0). Previous version: `19.0.0.7`.

- Column widths are remembered while a column is pinned: after you drag a column wider or narrower, the same widths come back the next time the list is opened (per view and per field of a form, like the pinned column).
- Pinning another column keeps the remembered widths. Unpinning the column (clicking its pin again) forgets them and the list goes back to the Odoo widths.
- Resizing a list with no pinned column stores nothing (Odoo behaviour unchanged).
- Tests: two new tours (widths come back, survive moving the pin, reset on unpin; nothing stored without a pin).
