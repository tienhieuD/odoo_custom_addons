# 12.0.0.6

Module `listview_sticky_header_and_column` (Odoo 12.0). Previous version: `12.0.0.5`.

- Fixed: in an editable list with a pinned column, the pinned cells of the row being edited are now above the pinned header and the other rows' pinned cells, so an open Many2one dropdown is no longer partly hidden under the header.
- Tests: one new tour (measures z-index and `elementFromPoint` on the dropdown items).
