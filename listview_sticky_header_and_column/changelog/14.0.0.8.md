# 14.0.0.8

Module `listview_sticky_header_and_column` (Odoo 14.0). Previous version: `14.0.0.7`.

- Column widths are remembered while a column is pinned: after you drag a column wider or narrower, the same widths come back the next time the list is opened (per model, and per field of a form, like the pinned column). In this Odoo version only editable lists have draggable columns, so only those are affected.
- Pinning another column keeps the remembered widths. Unpinning the column (clicking its pin again) forgets them and the list goes back to the Odoo widths.
- Resizing a list with no pinned column stores nothing (Odoo behaviour unchanged).
- Tests: two new tours (widths come back after a reload, survive moving the pin, reset on unpin; nothing stored without a pin).
