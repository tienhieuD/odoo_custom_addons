# 16.0.0.8

Module `listview_sticky_header_and_column` (Odoo 16.0). Previous version: `16.0.0.7`.

- Fixed: the handle (drag to reorder) column no longer gets a pin button. Every other data column still has exactly one (Odoo 16 has no `<column>` groups, so no column was missing a button).
- The pin button is now attached by `thead tr th[data-name], thead tr th[tabindex]` minus the checkbox, handle, button, open-form and optional-columns headers, as in 17 to 20.
- Tests: one new tour on the Order Lines of a sales order (button once per data column, none on the handle, pin keeps that column and all on its left while scrolling, unpin).
