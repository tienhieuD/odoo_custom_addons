# 12.0.0.7

Module `listview_sticky_header_and_column` (Odoo 12.0). Previous version: `12.0.0.6`.

- Fixed: the header (`thead`) is now sticky while scrolling vertically even when no column is pinned (Odoo 12 core has no sticky header; the old note saying it had one was wrong). The renderer element gets the class `lshc-sticky-head` and `main.scss` makes `thead` sticky (not for an x2many list inside a form).
- Fixed: the handle (drag to reorder) column and button columns no longer get a pin button.
- Tests: every tour is now strict (Odoo 12 swallows an error thrown in a tour step, so four tours failed silently before: header sticky, header sticky when pinned, pin column, unpin then reopen). Vertical scroll in those tours is now made by giving the table a height (a bottom margin did not create a scrollable area). One new tour on the Order Lines of a sales order.
