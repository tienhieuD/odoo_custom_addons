# 20.0.0.5

Module `listview_sticky_header_and_column` (Odoo 20.0). Previous version: `20.0.0.4`.

- Fixed: pinning the first column of a list (index 0, e.g. a list without the checkbox column) had no effect and the next click was read as "unpin". "Nothing pinned" is now `null` (the localStorage key is removed on unpin) and the saved index is compared strictly.
- Fixed: after unpinning, reopening the list (for example through a form and back) still attached an empty sticky style because the saved `-1` was truthy. No `-1` is stored any more, and one left by an older version is ignored and removed.
- Fixed: in dialogs (lists outside `.o_content`, such as Many2one "Search More") the pin button did nothing. The rules are now scoped to `.modal-body` as well, so the pinned column stays put on horizontal scroll and the header stays sticky.
- Tests: 13 (first column pin/unpin, unpin then reopen, pin inside a dialog measured with getComputedStyle / getBoundingClientRect).
