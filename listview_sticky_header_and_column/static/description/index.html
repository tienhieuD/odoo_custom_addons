List View Sticky Header & Freeze Column

Wide lists, long lists — you never lose the column that matters.

Hover a column header, click the pin, and that column (with every column to its left) stays in place while you scroll sideways. No settings, no setup.

Large tables are hard to read once you scroll: the first columns disappear and you no longer know which row you are looking at. This module adds a small pin button to the column headers of Odoo list views. Pin a column and it stays visible while the rest of the table scrolls, together with the header row.

What you get

Freeze columns

Click the pin on a column header to freeze it together with every column to its left. Click the pin again to release them.

Header stays in view

While columns are pinned, the header row also stays visible when you scroll down a long list.

Remembers your choice

The pinned column is remembered per list view in your browser and restored the next time you open it.

Works inside forms

Lists embedded in a form (order lines, invoice lines and other x2many fields) can be pinned too. Each list keeps its own pin.

Respects Odoo

Column widths and drag-to-resize keep working, and the pinned columns follow when you resize them. Colours come from your Odoo theme.

Zero configuration

No settings screen, no new menus, no data. Install it and the pin appears on the list headers.

How to use it

Three clicks, nothing to configure.

1. Hover a header

A small pin button appears on the column header.

2. Click the pin

The column and all columns to its left are frozen; the header row stays visible too.

3. Click again to unpin

Everything goes back to normal.

Pin a column in any list

The pin button shows up when you hover a header. Here the first columns stay in place while the rest of the table scrolls.

Also inside forms

Lists embedded in a form, such as the order lines of a quotation, can be pinned as well. Each list remembers its own pinned column.

Requirements & Installation

The module depends only on the standard base and web modules and needs no external Python library.

The pinned column is stored in the browser (local storage), so it is remembered per browser and per user session on that device. It is not shared between users or devices.

  • Use

Install the module

1. Copy the listview_sticky_header_and_column folder into an add-ons path of your Odoo server.

2. Restart Odoo, activate developer mode and click Update Apps List in the Apps menu.

3. Search for List View Sticky Header & Freeze Column and click Install.

Reload your browser page after installing so the new assets are loaded.

Pin and unpin a column

Open any list view and hover a column header. Click the pin button to freeze that column and the columns to its left.

Click the pin button on the same column again to unfreeze.

Pinning another column moves the frozen area to that column.

Frequently Asked Questions

Does it change my data or add fields?

No. It only changes how list views are displayed in the browser. It adds no models, fields, menus or settings.

Can I freeze several columns?

Yes. The pin freezes the chosen column and every column to its left, so pin the right-most column you want to keep in view.

Is my choice shared with other users?

No. It is remembered in your own browser only, per list view.

Will it work with my theme?

Header and row colours are taken from the Odoo theme variables, so it adapts to most themes. If you notice a conflict, please contact support.
