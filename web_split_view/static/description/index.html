Web Split View for Odoo

See the list and the record at the same time.

A new Split button appears in the view switcher of every list that has a form. The list stays on the left, the form of the selected record opens on the right.

Going back and forth between a list and a form costs time and context. With Web Split View you keep the list in front of you while you read, edit, create and delete records in the pane next to it. There is nothing to configure: the split view is built from the list, form and search views your action already uses.

What you get

Split on every list

Every window action that has a list and a form view gets a Split mode in its view switcher. It is added next to the list view and never becomes the default view.

Create, edit, delete in place

New, Save, Discard and Delete work in the right pane. The list refreshes by itself and the record you work on is highlighted.

Your list stays a list

The left pane keeps its own search bar, filters, group by and pager, using the search view of the action.

Full form in one click

An expand button on the right pane opens the record in the normal full form view. The breadcrumb brings you back.

Back where you left

Come back from the full form and the list still has its search, filters and page, and the same record is open and highlighted.

Resizable panes

Drag the divider to give more room to the list or to the form. The width is remembered for each action in your browser.

Safe when you switch

Clicking another record while the current one has unsaved changes asks you to save or discard first, like Odoo does anywhere else.

Works with standard lists

Lists of the standard apps, such as Sales, work too, including lists that use their own list renderer. In split mode a click on a row opens the record instead of editing the row.

Your control

Switch the automatic mode off for the whole database in Settings, or opt a single action out. You can still define your own split view with chosen list and form views.

How to use it

Three clicks, nothing to install on your data.

1. Click Split

In the view switcher of any list, click the Split button (two columns).

2. Select a record

Click a row: its form opens on the right and the row is highlighted.

3. Work next to the list

Edit and save, create with New, or expand the record to the full form.

The list and the form, side by side

Sales orders in split mode. The list keeps its search bar and pager, the order opens on the right with its lines, and the expand button in the corner opens the full form.

One click away on every list

The Split button sits in the view switcher, right after the list view.

Create records without leaving the list

Click New and the form of the new record opens on the right. Save it and the list shows it right away.

Come back to the same place

Open the record in the full form, use the breadcrumb to go back, and the split view is exactly as you left it.

Requirements & Installation

The module depends only on the standard web module and needs no external Python library. It adds no data and no menu.

The width of the panes is stored in the browser (local storage), so it is remembered per browser and not shared between users or devices.

Install the module

1. Copy the web_split_view folder into an add-ons path of your Odoo server.

2. Restart Odoo, activate developer mode and click Update Apps List in the Apps menu.

3. Search for Web Split View and click Install.

Reload your browser page after installing so the new assets are loaded.

Open the split view

Open any list that has a form view, for example Sales Orders or Contacts, and click the Split button in the view switcher.

Click a row to open it on the right. Use New to create a record in the right pane.

In split mode a click on a row always opens the record on the right: lists are not edited inline.

Turn it off or customise it

Settings > Split View switches the automatic Split mode on or off for the whole database.

In developer mode, tick No split view on a window action to opt that action out.

You can also create your own split view for an action with the list and form views you choose, from the developer mode debug menu.

Frequently Asked Questions

Does it change my data or my views?

No. It only changes how a list and its form are displayed in the browser. It adds no field to your models and does not modify your list or form views.

Which views does the split mode use?

The list, form and search views of the action you are in, so a customised list or form shows up exactly as you set it.

What does the list remember when I leave and come back?

After a visit to the full form, the list keeps its search, filters, group by and page, and the same record is shown and highlighted. After a page reload the same record is reopened. The width of the panes is remembered in your browser for each action.

Can I still edit a list inline?

In the normal list view, yes. In split mode a click on a row opens the record in the right pane instead.

Can I switch it off?

Yes: Settings > Split View turns the automatic mode off for the whole database, and a single action can opt out from developer mode.

Can I choose the views of a split view myself?

Yes. A custom split view can name the list and form views to use, or define them directly inside it.

Stop jumping between list and form.

Install it, open a list and click Split. That is all it takes.
