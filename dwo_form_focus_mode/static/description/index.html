Form Focus Mode

Wider forms, one click.

Order lines, long forms and wide tables need room. One button gives the form view the whole width, and the chatter is still one click away.

On a large screen Odoo keeps the chatter beside the form and limits the width of the sheet, so wide order lines and many columns get squeezed. Form Focus Mode adds a button, with an icon and a label, to the control panel of every form, just before the pager, that switches between three layouts. Nothing to configure.

What you get

Three layouts

Normal: the form as Odoo shows it. Wide: the chatter is out of the page and the sheet uses the full width. Focus: the same, and the top navigation bar is hidden too.

Chatter as a drawer

While the chatter is hidden, a round button opens it as a drawer on the right: messages, notes, activities, followers and attachments, without leaving the form. Close it and the form is full width again.

Remembered per model

Sales orders can stay in focus mode while contacts stay normal. The layout is kept in your browser for each model and comes back the next time you open a form of that model.

Keyboard shortcut

Alt+Shift+F cycles the layouts (Ctrl+Shift+F on a Mac, where Odoo reads Ctrl as Alt). The button before the pager shows what a click does: Wide form, Focus mode or Normal form; its outline takes the colour of your theme while a layout is on.

Safe for your data

It only changes how the form is laid out in the browser. No models, no fields, no menus, no data; it depends only on the standard web module.

Leaves dialogs and phones alone

Forms in a dialog, and forms on a phone, keep their normal layout: there the form already has the whole screen.

Normal: the chatter beside the form

The default Odoo layout on a large screen. The new button, with its label, sits just before the pager.

Wide: the whole width for the form

The chatter is out of the page, the lines and columns have room, and a round button at the bottom right brings the chatter back when you need it.

Limitations

What to expect, so there are no surprises.

Remembered in the browser

The layout is stored in the browser (local storage), per model: it is not shared between devices or browsers, and a private window starts in the normal layout.

Focus hides the top bar

In focus mode the app menu is hidden. Click the button (or press the shortcut) to bring it back, or use the breadcrumb in the control panel to leave the form.

Attachment panel and sheet chatter

The attachment preview panel that some forms show beside the sheet is not changed. A form that puts its chatter inside the sheet keeps it there.

Large screens

On a narrow window Odoo already puts the chatter under the form; the button still hides it and the drawer still shows it.

Requirements & Installation

The module depends only on the standard web module and needs no external Python library.

  • Install

Install the module

1. Copy the dwo_form_focus_mode folder into an add-ons path of your Odoo server.

2. Restart Odoo, activate the developer mode, update the apps list, and install Form Focus Mode.

3. Open any form view: the button is in the control panel. No settings, menus or data are added.

Frequently Asked Questions

Does it change my data or add fields?

No. It only changes the layout of form views in the browser.

Where do I find the chatter in wide and focus mode?

A round button at the bottom right opens it as a drawer on the right side of the screen. The same button closes it.

Can I choose a layout for every model?

Yes, it is remembered per model: use the button or Alt+Shift+F (Ctrl+Shift+F on a Mac) on a form and the choice stays for that model.

Which Odoo versions?

The same module is published for the recent Odoo releases, Community and Enterprise: pick your version in the version selector of this page.
