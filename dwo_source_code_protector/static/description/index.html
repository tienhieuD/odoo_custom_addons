Frequently Asked Questions

Will my module still install and upgrade normally?

Yes. The protected module preserves the complete class structure — all fields, decorators, and _name/_inherit are untouched. Odoo registers the model exactly as before. Clients will never notice the difference at runtime.

Can clients decompile the binary?

Native binaries are dramatically harder to reverse-engineer than Python bytecode (.pyc). Decompiling requires significant expertise and effort — a strong practical deterrent for most IP theft scenarios.

Can I protect multiple modules at once?

Yes. Upload a zip with any number of modules. The tool auto-detects all module roots, protects each independently, and returns one output zip with the same structure — all modules included, protected ones swapped in-place.

Does zip password protection work?

Yes. Enter a password in the wizard — the tool decrypts the input zip and re-encrypts the output zip with the same password using AES-256.

What needs to be installed on the Odoo server?

Two packages: jprotect and pyzipper. Run pip install jprotect pyzipper. Odoo will display a clear error if either is missing.

Is my source code sent to any external service?

No. Everything runs locally on your Odoo server. No data leaves your instance.
