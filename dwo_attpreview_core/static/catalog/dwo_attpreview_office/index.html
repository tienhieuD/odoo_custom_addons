Your files never leave your Odoo server

Word, Excel and PowerPoint files are never sent to Microsoft, Google or any other online viewer, conversion service or CDN. The viewer is shipped inside the module and draws the file in the browser of the user who opens it, inside an isolated frame that cannot reach the internet. Built for contracts, payroll, financial and other sensitive documents.

Click a .docx, .xlsx or .pptx attachment in the chatter, or the Preview button of a file field, and the document opens in a large dialog. The file goes only from your Odoo server to the browser of the user who is allowed to read it. The viewer is bundled in the module and draws the document in that browser, inside an isolated frame that has no network access. Nothing is uploaded to a third-party service, and no CDN or web font is loaded. This engine works with the free Secure Attachment Preview module (dwo_attpreview_core), installed automatically as a dependency.

Why It Is Safe for Sensitive Documents

Never leaves your server

No online document viewer, no conversion service, no CDN, no Google Fonts. The viewer libraries are shipped inside the module, so the preview also works on a server without internet access.

Isolated viewer frame

The document is drawn in a sandboxed frame (scripts only, no same-origin access) with a Content Security Policy of default-src 'none': it cannot read your Odoo session or page, and it can load files only from your own server.

Same rights as Odoo

A user can preview a file only if Odoo lets them read that attachment or record. The access is checked again when the file is sent to the viewer.

Macros never run

Macro-enabled files (xlsm, docm, pptm...) open as plain documents. The macro part is not read, no code of the document is executed, and links inside documents are disabled.

Checked before opening

Size limit (default 20 MB, set in Settings). Office files are checked as sane archives with limits on unpacked size and number of parts (zip bombs are refused). XML is read as data only. Old .doc/.xls/.ppt files are parsed in the browser, never in the Odoo server process.

No tracking, no key

The module collects no data, sends no statistics and needs no activation key or account.

Supported file types

Full support: docx, xlsx, pptx, csv, tsv.

Variants (shown as their base format, macros never run): xlsm, xltx, xltm, docm, dotx, dotm, pptm, ppsx, ppsm, potx, potm. A slideshow file opens as normal slides.

Limited support, with a warning: doc, xls, ppt.

Not supported: odt, ods, odp, xlsb, rtf and password-protected files. They get the short notice with a Download button.

What happens to a file

1. The user clicks a file. Odoo checks that this user can read the attachment or the record, applies the size limit and checks the file structure.

2. The browser of that user receives the original file from your Odoo server only, through a route that checks the access again.

3. The bundled viewer draws it inside a sandboxed frame. Its Content Security Policy blocks every address except your own server, so the document cannot call out to the internet, and the frame cannot read the Odoo session.

Rendered results kept by the preview cache are readable only by administrators and are cleaned automatically. A file stored in a binary field outside attachments is checked in memory and no copy is created.

Good to know

Old formats (.doc, .xls, .ppt): support is limited. Some files show incorrectly or cannot be opened (for example .doc files with hyperlinks, merged table cells, footnotes or most pictures, and encrypted files); the user then gets a short message and a Download button. In our tests with public sample files, about 70% of .xls and .ppt files and about 40% of .doc files opened.

Formulas are not recalculated: the value stored in the file is shown.

Display can differ slightly from Microsoft Office (fonts, some drawing types). Text is drawn on a canvas, so it is selected with the viewer, not like normal page text.

CSV/TSV: UTF-8 only, default column width, up to 200,000 rows.

The labels of the viewer toolbar and search bar are in English.

Requirements

Odoo Community or Enterprise, on premise or on Odoo.sh. Odoo Online is not supported (it cannot install third-party modules).

Depends on Secure Attachment Preview (dwo_attpreview_core, free), installed automatically. No Python library to add, no system package, no internet access needed.

A recent desktop browser (Chrome, Edge, Firefox, Safari) with WebAssembly. After installation the engine is ready: there is nothing to configure. The size limit is in Settings → Attachment Preview.

Frequently Asked Questions

Is my document sent to Microsoft, Google or any other service?

No. The file goes from your Odoo server to the browser of the user who opened it, and is drawn there by a library shipped inside the module. No online viewer, CDN or font service is called.

Can someone see a file they are not allowed to open?

No. The preview follows the Odoo access rights of the attachment or the record, and the access is checked again when the file is sent to the viewer.

Do macros run?

No. Macro-enabled files are shown as plain documents; the macro part is not read and no code of the document is executed.

Why do old .doc, .xls and .ppt files show a warning?

Their binary format is only partly supported. Many files open well, but some show differences or cannot be opened. The warning says so, and a Download button is always there.

Does it change or convert my files?

No. The original file is never modified and no converted copy is stored.

Can I preview files stored in custom binary fields?

Yes. File fields get a Preview button; an Office file in a binary field of any record opens in the same viewer, with the same access checks.
