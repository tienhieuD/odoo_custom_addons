Secure 3D Preview: STL, STEP, OBJ, GLB, 3DM

Open 3D models and CAD solids right inside Odoo.

Rotate, zoom and inspect STL, OBJ, GLB, GLTF, 3MF, PLY, FBX, DAE, STEP, IGES and Rhino 3DM files from the chatter or a file field.

Click a 3D file in the chatter or in a file field and it opens in a large dialog. Drag to rotate, scroll to zoom, right-drag to pan. The toolbar fits the model in the view, switches the wireframe, a grid, the axes and a dark background, and shows the triangle count and the size of the model. Works with the free Secure Attachment Preview module, installed automatically.

Key Features

Eleven formats

STL (binary and ASCII), OBJ, GLB, GLTF with the data inside, 3MF, PLY (also point clouds), FBX, DAE, STEP and STP, IGES and IGS, and Rhino 3DM.

CAD solids from STEP and IGES

Open CASCADE turns the solids and surfaces into meshes in your browser, with the colours of the file. Loaded only when such a file is opened.

Orbit, zoom, wireframe

Reset view, wireframe, grid, axes and a dark background. Models stored with Z up are turned upright.

Files never leave your server

The viewer is bundled in the module and runs in a sandboxed frame with no network access. Nothing is uploaded to a conversion service, a CDN or any other site.

Same rights as Odoo

A user can preview a file only if Odoo lets them read that attachment or record. The check is made again when the file is handed to the viewer.

Size limits you control

Each group of file types has its own limit in Settings, so a large model does not slow the server.

Frequently Asked Questions

Which files does it open?

STL, OBJ, GLB, GLTF, 3MF, PLY, FBX, DAE, STEP (stp), IGES (igs) and 3DM.

Why does my GLTF file not open?

A .gltf file that refers to separate .bin or image files cannot work, because the viewer receives one file. Use a .glb, or a .gltf with the data inside. The preview says so.

Are textures shown?

Colours and materials stored in the file are. Textures kept in separate files next to a model are not loaded.

Does a Rhino file always show?

Meshes and the render meshes that Rhino saves with solids are shown. A solid saved without a render mesh shows nothing, and the preview says the file has nothing to show.

Is anything sent to another server?

No. Even the STEP and Rhino readers run in your browser, from files of the module.

How large can a file be?

Each group of formats has a limit in Settings: 50 MB for meshes and scenes, 25 MB for STEP and IGES and 50 MB for 3DM by default. A larger file is not previewed and can be downloaded.
