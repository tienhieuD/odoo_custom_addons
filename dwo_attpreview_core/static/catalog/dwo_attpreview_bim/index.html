Secure BIM Preview: IFC models

Open IFC building models right inside Odoo.

Orbit around a building, hide storeys and read the properties of any element, from the chatter or a file field.

Click an IFC file in the chatter or in a file field and the model opens in a large dialog. Drag to orbit, scroll to zoom. The Structure panel lists the project, site, building and storeys with a switch to show or hide each one. Click an element to highlight it and read its type, its GlobalId and its property sets. Works with the free Secure Attachment Preview module, installed automatically.

Key Features

3D view with the colours of the model

Walls, slabs, columns, windows and the rest are drawn with the colours and the transparency stored in the file.

Building structure

Project, site, building and storeys as a tree; untick a storey to look inside the one below.

Element properties

Click an element to highlight it and see its type, name, GlobalId and its property sets.

Files never leave your server

The viewer is bundled in the module and runs in a sandboxed frame with no network access. Nothing is uploaded to a conversion service, a CDN or any other site.

Same rights as Odoo

A user can preview a file only if Odoo lets them read that attachment or record. The check is made again when the file is handed to the viewer.

Size limits you control

Each group of file types has its own limit in Settings, so a large model does not slow the server.

Frequently Asked Questions

Which files does it open?

IFC files (IFC2x3 and IFC4) that web-ifc can read. Compressed ifczip and ifcxml files are not opened. Models made in Revit, ArchiCAD and similar tools can be exported to IFC.

Can it open Revit (rvt) or SketchUp (skp) files?

No. Export the model to IFC, or to GLB for the Secure 3D Preview module.

Is anything sent to another server?

No. The model is read and drawn in your browser, in a sandboxed frame with no network access.

How large can a file be?

100 MB by default; change it in Settings. Large models take time to open and use the memory of the computer of the person who opens them.
