Secure Attachment Preview

Your documents never leave your Odoo server.

Preview attachments and file fields in a large dialog, with Odoo access rights, without any external service.

Click an attachment in the chatter, or the Preview button of a file field, and the file opens in a large dialog instead of being downloaded. PDF, images, video and audio are shown by the browser itself from your Odoo server. Other file types are handled by preview engines, separate modules that you tick in the Settings (for example Secure Office Preview for Word, Excel and PowerPoint files). Every preview follows the Odoo access rights, and no file is sent to an outside service.

Built for Private Documents

No outside service

No online viewer, no CDN, no conversion service. Files go from your Odoo server to the browser of the user who opens them, and nowhere else.

Odoo access rights

A file can be previewed only by a user who can read the attachment, or the record and field that holds it. Anyone else gets “You are not allowed to see this file.”

Limits and cache

A maximum file size (default 20 MB) is set in Settings. Rendered results are cached, readable only by administrators, and cleaned automatically every day.

Key Features

Large preview dialog

Almost the whole window, with a full screen button, Download, and Open in a new tab for PDF and media. Esc closes it.

PDF, images, video, audio

PDF in the browser's own viewer; PNG, JPEG, GIF, WebP, AVIF, BMP and SVG images; video and audio with player controls.

Preview buttons on file fields

Binary fields of any model, many2many_binary fields, lists and kanban of attachments, and many2one fields to an attachment get a Preview (eye) button. Odoo's own buttons stay unchanged.

Clear notice when not possible

A file that cannot be previewed opens no empty dialog: a short notice gives the file name, the reason and a Download button.

Engines in Settings

Each preview engine is a tick box in Settings → Attachment Preview. Tick and save to install an engine that is in your addons; for one that is not, a window shows what it previews.

Free and open

LGPL-3, no activation key, no account, no data collection. Works with Odoo Community and Enterprise.

How files are protected

Every preview request checks the Odoo read access of the attachment, or of the record and the field that holds the file. Files are served only by your Odoo server; nothing is uploaded elsewhere and no CDN or web font is loaded.

HTML produced by an engine is shown in a sandboxed frame without scripts. Engines that draw files in the browser, such as Secure Office Preview, use their own isolated frame.

A file in a binary field stored outside attachments is checked in memory: no attachment and no cache entry are created.

Good to know

On its own this module previews PDF, images, video and audio. Office, email and other file types need the matching engine module.

PDF uses the PDF viewer of the browser. A file just uploaded to a field can be previewed after the record is saved.

Very large files are refused by the size limit and get the notice with a Download button.

Requirements

Odoo Community or Enterprise, on premise or on Odoo.sh. Depends only on the standard base, web and mail modules. No Python library to add.

Odoo Online is not supported (it cannot install third-party modules).

Frequently Asked Questions

Are my files sent to an outside service?

No. Files are served by your Odoo server to the browser of the user who opens them.

Who can preview a file?

Only users who can read it in Odoo: the attachment, or the record and the field that holds it.

Which files can be previewed without an engine?

PDF, common image formats, video and audio that the browser can play.

How do I preview Word, Excel or PowerPoint files?

Add the Secure Office Preview engine to your addons, then tick it in Settings → Attachment Preview and save.

Does it change Odoo's download or upload buttons?

No. It only adds a Preview button; the existing buttons keep working as before.
