Login Page Themes

A better first impression for your Odoo.

Change only the look of the login page: layout, colours, background, logo and a fixed announcement. The form and every sign-in option stay exactly as Odoo made them.

The login page is the first thing your people and your customers see. Login Page Themes gives it a layout and colours that fit your company, from one Settings screen. It restyles the standard page with CSS: it does not replace the form, so reset password, sign up, OAuth, passkeys, two-factor, the database selector and the fields other modules add keep working as before.

14 layouts to choose from

Centered card, split screens, side columns, glass, animated gradient, minimal, dark, top bar, bottom-right corner, intro panel and card in a card. Each one is a different look of the same Odoo form.

What you get

Preview tiles in Settings

Pick the layout from 14 small previews drawn in pure CSS. Eight colour presets set the main, button, text and card colours with one click; you can still adjust each colour.

Backgrounds, free and yours

20 bundled images made for this module (soft colour fields and geometric patterns), your own picture, a solid colour or a gradient, with a dark overlay and a blur you control.

Images that change

A random image at each visit, one per day, by time of day (morning, day, evening, night) or a gentle slideshow, chosen from a group of images.

Your logo and words

A logo for the login form (the company logo by default), a welcome title and text, an intro panel with up to six points, a footer line and the title and icon of the browser tab.

A fixed announcement

Type HTML in Settings and it is shown on the login page to everybody, signed in or not: information, success, warning or error, above or below the form or as a banner, with a close button and start and end dates. It is cleaned when saved and at every display.

Show or hide the password

A small eye button in the password field on the Odoo versions whose login page has none. It is added only when missing and can be switched off.

Split screen with an intro panel

The image on one side, the form on the other, with your own title and points over the picture.

Glass card on a soft background

A translucent card with blur, in the colours of the preset you pick. The footer line is optional.

Dark

A dark card for a night look; the sign-in options stay readable.

An announcement on the login page

A warning about a planned maintenance, shown to everybody above the form, with a close button. The text is HTML you type in Settings; scripts, forms and images are removed.

Layouts, colours, backgrounds and announcement in one screen

Everything is in Settings, Login Page Themes. The layout and preset tiles are plain CSS drawings.

Safe by design

The form is not replaced

Only classes, a background layer and some text are added around Odoo's own login form. Passwords, two-factor codes, OAuth buttons, sign up and reset password keep Odoo's own code and every other module that adds to the form still shows up.

The announcement is sanitized twice

When you save and again every time the page is shown. Only simple text tags are kept; links must be http, https or mailto and open with rel="noopener noreferrer". Scripts, styles, frames, forms, images and on* attributes are removed, even if the setting was edited directly in the database.

Uploads are checked

JPEG, PNG or WebP only (no SVG), up to 6 MB, decoded and recompressed so the login page stays light. The public image route serves only the files saved by this module in its own settings.

Only the look

No change to authentication, sessions, passwords or access rights, and the "Powered by Odoo" line is not touched. It depends only on the standard web module.

Limitations

What to expect, so there are no surprises.

With the Website app

When Website is installed, Odoo draws the login page inside the layout of the website. The module leaves that page as it is: no layout, colours or background, but the announcement is still shown above or below the form.

One look for the whole database

The settings are global: one look for all companies and domains.

Time of day uses the server

"By time of day" follows the server clock and the time zone of the main company, not the clock of the visitor.

The close button is per browser

A closed announcement is remembered in that browser only, until the text changes.

Small JavaScript file

The layouts are CSS only. A small plain script closes the announcement, sets the tab title and icon and adds the password button. The page still works without it.

Requirements & Installation

The module depends only on the standard web module. It needs the Python library Pillow, which Odoo already requires.

Install the module

1. Copy the dwo_login_themes folder into an add-ons path of your Odoo server.

2. Restart Odoo, activate the developer mode, update the apps list, and install Login Page Themes.

3. Open Settings, then Login Page Themes, pick a layout and save. Open the login page in a private window to see it.

Where everything is

Settings, Login Page Themes (system administrators). The values are saved as system parameters dwo_login.*.

Switch off Apply the theme to get the standard login page back; the announcement has its own switch.

Frequently Asked Questions

Does it change how people sign in?

No. It only changes how the page looks. The form, reset password, sign up, OAuth, passkeys, two-factor and the database selector are Odoo's own.

Can I put a script or an image in the announcement?

No. Scripts, styles, frames, forms and images are removed. You can use headings, bold, italic, lists, links (http, https, mailto), spans, divs and rules.

Can I use my own background and logo?

Yes: upload a JPEG, PNG or WebP image. It is checked and recompressed. The company logo is used when you do not upload one.

Are the bundled images free to use?

Yes. They were made for this module (no photographs, no third-party artwork) and come with it.

Does it work with other login modules?

It works with the modules that add buttons or fields to Odoo's login form, because the form is not replaced. A module that replaces the whole login page can conflict, as with any other theme.

Does it hide Powered by Odoo?

No. The module changes only the look and leaves that line as it is.

Which Odoo versions?

The same module is published for the recent Odoo releases, Community and Enterprise: pick your version in the version selector of this page.
