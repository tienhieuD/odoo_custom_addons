Secure CAD Preview: DXF drawings

Open DXF drawings right inside Odoo.

Pan, zoom and switch layers of a 2D drawing from the chatter or a file field, without CAD software.

Live demo: demo-attpreview.duotek.io.vn (sign in as demo_alice, password demo)

Click a DXF file in the chatter or in a file field and the drawing opens in a large dialog. Drag to pan, scroll to zoom, and use the Layers list to show or hide each layer. Reset view fits the whole drawing. Works with the free Secure Attachment Preview module, installed automatically. For DWG files, the free Secure DWG Preview module does the same.

Key Features

Drawings, not pictures

Lines, polylines, arcs, circles, ellipses, splines, hatches, blocks, dimensions and text are drawn as vectors, so you can zoom in without losing sharpness.

Layers

A list with the colour of each layer and a switch to show or hide it. Black and white entities are inverted on a dark background so they stay visible.

Text in any language

Text is drawn with a bundled font that covers Latin, extended Latin and Vietnamese letters.

Files never leave your server

The viewer is bundled in the module and runs in a sandboxed frame with no network access. Nothing is uploaded to a conversion service, a CDN or any other site.

Same rights as Odoo

A user can preview a file only if Odoo lets them read that attachment or record. The check is made again when the file is handed to the viewer.

Size limits you control

Each group of file types has its own limit in Settings, so a large model does not slow the server.

Frequently Asked Questions

Which files does it open?

ASCII DXF files. A binary DXF is refused with a message that asks for an ASCII DXF. For .dwg files install the free Secure DWG Preview module.

Is everything in the drawing shown?

The common 2D entities are. 3D solids and pictures are not drawn.

Do fonts match the original?

No. Text is drawn with the bundled font, so shapes and widths can differ from the CAD program.

Is anything sent to another server?

No. The drawing is read and drawn in your browser, in a sandboxed frame with no network access.

How large can a file be?

30 MB by default; change it in Settings. A larger file is not previewed and can be downloaded.
