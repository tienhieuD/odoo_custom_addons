Secure WebGL Preview Base

The shared base of the Secure 3D, CAD, BIM and DWG preview modules.

Installed automatically with them. It previews no file by itself.

This module holds what the design-file preview modules share: three.js (MIT), the sandboxed viewer frame with orbit controls, fit-to-view, wireframe, grid, axes and background switches, and the routes that hand a file to the frame after the access checks. Install Secure 3D Preview, Secure CAD Preview, Secure BIM Preview or the free Secure DWG Preview to open files.

What It Provides

One copy of three.js

The 3D, CAD, BIM and DWG modules draw with the same copy, so it is downloaded once.

Sandboxed frame

Files are drawn in an iframe with no network access and no access to your Odoo session.

Files never leave your server

The viewer is bundled in the module and runs in a sandboxed frame with no network access. Nothing is uploaded to a conversion service, a CDN or any other site.

Frequently Asked Questions

Do I need to install it?

It is installed automatically when you install one of the design-file preview modules.

Which files does it open?

None by itself. The modules that depend on it open STL, STEP, DXF, DWG, IFC and other design files.
